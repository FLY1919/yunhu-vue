# 云湖牢大版 v1.0.1

云湖第三方桌面客户端。本版在 v1.0.0 的 QQ 式界面基础上，完成一轮完整的功能与体验升级。

## 新增功能

- **锁屏与手机解锁**：菜单「锁定」后全屏锁定；支持 PIN 密码解锁，或向同账号的手机端发送解锁请求、由手机弹窗确认解锁
- **@群成员**：输入框中输入 @ 弹出群成员列表，支持继续输入搜索、方向键选择
- **会话免打扰**：右键会话或群设置中开启；开启后该会话不计入未读角标
- **会话置顶与删除**：右键会话可置顶（本地排序）或从列表删除（仅本地隐藏，不删云端记录）
- **表情包分组**：表情面板新增表情包组页签，收藏与各表情包分组展示
- **更多功能管理**：左侧竖条宫格入口；点「管理」进入编辑态，可将功能常驻到竖条并拖拽排序
- **关于页**：菜单「关于」，含项目介绍、双仓库链接与数据目录自定义
- **更新检查**：菜单「检查更新」；有新版本时弹窗可选「去 Release 更新」（国内加速链接）或「暂不更新」

## 体验改进

- **输入区**：顶边可拖拽调整高度；粘贴/拖入的图片视频先暂存预览，可裁剪、旋转、配文后再发送；上传显示进度条与实时速度；超出大小限制即时提示
- **暂存不丢失**：切换会话或页面刷新后，未发送的附件仍保留在对应会话
- **消息定位**：非文本消息右键「在文件夹中打开」，在群文件面板中高亮定位
- **回最新**：上翻历史时右下角出现箭头，一键回到最新消息
- **弹窗层级**：所有菜单、面板、对话框层级理顺，不再互相遮挡；点空白处即可关闭；确认框统一为应用内风格
- **群文件**：群自带网盘为空但存在第三方挂载盘时，自动进入挂载盘浏览
- **连接状态**：断线重连改为标题栏小黄点提示，不再占据按钮位置

## 修复

- 已打开的会话仍显示未读气泡的问题（含重启后复现）
- 创建群聊偶发卡住、失败时误报成功
- 文章卡片无法打开、带图文章图片不显示
- 音视频消息发送后无法播放
- 安卓端启动黑屏（构建兼容性 + 启动失败可视化提示）
- 若干图标不居中、菜单被遮挡的问题

## 平台说明

- Windows / macOS / Linux：桌面客户端，内置服务，双击即用（未签名，安装时请允许）
- 安卓：本版安卓端（WebView 方案）体验有限，推荐使用原生实现 [Yhchat_md3](https://github.com/Kauid323/Yhchat_md3) 或 [Murexide](https://github.com/murexide-project/Murexide)

## 数据与隐私

- 登录信息与会话缓存保存在你的文档目录（默认 `文档/yhchat`，可在关于页自定义）
- 退出账号将清除全部本地凭据；主题、快捷回复等个人偏好保留
