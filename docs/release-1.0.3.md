# 云湖牢大版 v1.0.3

第三方桌面客户端。本版为体验与协议对齐的集中修复版。

## 新增

- **群聊卡片分享**：群设置「分享」生成官方格式分享链接与二维码；也可把群以卡片消息发给好友/群聊，收到的人点开卡片可一键「加入群聊」或「发消息」
- **群二维码分享**：群面板「分享」生成群二维码与分享链接，扫码进群
- **邀请入群**：支持好友/群聊筛选、多选、确认发送（发给群聊时自动发群卡片）
- **退出群聊**：群设置底部新增退群按钮（群主需先转让/解散）
- **全局搜索**：侧栏回车搜人/群/机器人；聊天记录搜索可点击精准跳转（持续高亮框 + 「回到最新」入口）
- **表情合集**：面板按合集分页签；管理页点击表情包展开全部内容并可继续添加；每格显示文件名；右键收藏/重命名；聊天里点表情可定位到它所在合集并圈线高亮
- **群管理补全**：设撤管理员、消息自动删除、入群口令、编辑群资料、群盘重命名删除、第三方网盘挂载增删与页内上传；成员「管理」改为居中弹窗（禁言/设管理/打标签/资料/踢出集中一处）
- **账号页补全**：在线设备、金币明细、好友备注云同步、拉黑
- **锁屏忘记密码**：账号密码或 token 验证身份后重设 PIN
- **发现页**：通讯录新增推荐分区与推荐群浏览；板块页默认进「热门」
- **数据目录**：关于页可自定义数据目录与文件保存目录，支持「浏览…」弹系统文件夹选择框或直接粘贴路径
- **托盘菜单**：系统托盘右键可退出应用（自动清理后台服务）

## 体验改进

- **默认主题「科比紫」**：Material 3 质感，全 UI 随主题强调色联动，页面保持深色
- **气泡**：宽度随文本、贴近头像、双方圆角一致、己方淡紫；Markdown 消息行距收紧
- **群设置**：右侧固定面板直开直关；群看板可展开/全屏查看；群成员不再误显禁言
- **图片查看**：滚轮缩放、拖拽平移、双击放大；视频应用内全屏 + 消息上显式「放大」按钮
- **时间显示**：点击消息时间可在简短与「完整日期+秒」之间切换
- **免打扰标识**：会话列表免打扰会话名字旁显示灰色铃铛图标
- **上传限制**：超过 40MB 的文件在放入待发送区时即拦截并说明原因；发送失败提示显示真实原因
- **细节**：会话列表小圆角、关闭按钮正圆居中、开窗无闪动、多行输入至少 3 行、长公告可展开、消息三点按钮移除（操作走右键）、撤回前弹确认框

## 修复

- 聊天记录搜索不显示内容、跳转不精准；引用图片/消息点击无法定位
- 消息编辑点击无反应
- 自建表情包裂图、移动端无法识别桌面创建的合集与收藏表情（发送协议对齐官方）
- 搜索跳转后无法返回最新
- 版本号硬编码问题：改为构建期注入，检查更新不再误报自身为旧版
- **连接状态**：修复「一直重连中」——连接被秒断时重连计数不再被错误归零，恢复后自动回到在线
- **稳定性**：修复个别响应导致整个应用闪退/页面停住的问题（代理层加固）
- 群文件删除失败；群盘重命名报错
- 聊天中文章卡片打不开；板块文章详情为空
- 保存文件失败、「在文件夹中打开」不弹资源管理器
- 板块头像不显示；板块页刷新与页签不一致

## 平台说明

- **Windows（Tauri 版）**：安装包 23MB、便携版 35MB，系统 WebView2 内核；自本版起为唯一桌面发布形态
- Electron 桌面端与安卓端自本版起停止构建与发布，旧产物已从 Release 移除
- 安卓客户端推荐原生实现：[Yhchat_md3](https://github.com/Kauid323/Yhchat_md3) 或 [Murexide](https://github.com/murexide-project/Murexide)

## 数据与隐私

- 登录信息与会话缓存保存在文档目录（默认 `文档/yhchat`，关于页可自定义）
- 退出账号清除全部本地凭据；个人偏好保留
