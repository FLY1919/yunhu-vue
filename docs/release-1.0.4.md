# 云湖牢大版 v1.0.4

第三方桌面客户端。本版为群卡片生态、稳定性与一批实测反馈的集中修复版。

## 新增

- **群聊卡片**：群设置「分享」可生成官方格式分享链接与二维码；也可把本群以卡片消息分享给好友/群聊/本群（转发同款大页面选择目标）
- **卡片一键加群**：收到群卡片点击弹出确认框——未加入显示「加入群聊」，已加入显示「发消息」
- **表情合集浏览**：聊天里点未收藏的表情，面板列出该合集全部表情并框住点的那张，可一键「添加合集」
- **表情管理增强**：多选支持全选/反选；页面内 Ctrl+V 直接粘贴图片上传到展开的合集
- **退出群聊**：群设置底部新增退群按钮（群主需先转让/解散）
- **托盘菜单**：系统托盘右键可退出应用（自动清理后台服务）
- **数据目录浏览**：关于页自定义目录支持「浏览…」弹系统文件夹选择框

## 体验改进

- **上传提示**：超过 40MB 的文件在上传失败时明确提示大小限制与当前文件大小
- **时间显示**：点击消息时间可在简短与「完整日期+秒」之间切换
- **免打扰标识**：会话列表免打扰会话名字旁显示灰色铃铛，且免打扰状态同步云端
- **视频放大**：消息上的视频新增显式「放大」按钮，点开即全屏播放

## 修复

- **启动稳定性**：修复后端服务未就绪时白屏/闪退——等待时间延长并自动重试拉起，失败显示中文错误页与真实原因，「重试」按钮真正重启后台服务
- **连接状态**：修复「一直重连中」——连接被秒断时重连计数不再被错误归零，恢复后自动回到在线
- **整体闪退**：修复个别网络响应导致整个应用崩溃的问题（代理层加固）
- **图片显示**：修复聊天图片不加载/气泡塌缩的问题
- **表情手机端识别**：发送字段对齐官方手机端真实消息格式（第三轮修正，以官方样本为准）
- **群文件**：删除失败、重命名报错修复
- **引用/搜索定位**：引用图片点击无法定位、二次跳转失败修复
- **文章**：聊天中文章卡片打不开修复
- **板块**：默认进「热门」、头像不显示、刷新与页签不一致修复

## 平台说明

- **Windows（Tauri 版）**：安装包约 23MB、便携版约 35MB，系统 WebView2 内核；安装目录为英文 YunhuLaoda，桌面/开始菜单快捷方式为中文「云湖牢大版」
- Electron 桌面端与安卓端自 1.0.3 起停止构建与发布
- 安卓客户端推荐原生实现：[Yhchat_md3](https://github.com/Kauid323/Yhchat_md3) 或 [Murexide](https://github.com/murexide-project/Murexide)

## 数据与隐私

- 登录信息与会话缓存保存在文档目录（默认 `文档/yhchat`，关于页可自定义）
- 退出账号清除全部本地凭据；个人偏好保留
