# 聊天、引用、主题及通知修复

基线：`036d87dcb17337e978562521e8fe3c2e36aeb5bb`，1.0.4；工作分支：`fix/chat-interaction-performance`。
采用增量修改，保留 Enter 发送、Shift+Enter 换行，未变更版本号或发布 Release。

## 修复内容

| 问题 | 根因与修改 |
| --- | --- |
| 切换会话后消息、历史或搜索结果串入新会话 | 请求完成时没有核对当前会话和请求代次。增加会话/请求版本保护；搜索只接受最后一次结果。 |
| 轮询叠加、历史阅读位置被破坏 | 慢请求可跨轮询间隔重叠，后台补消息会裁掉正在阅读的旧消息。静默请求去重，历史定位期间不拉最新，非贴底阅读时保留消息窗口。 |
| 草稿和附件丢失、监听器累积 | 原 Map 写在 SFC setup 内，组件重建后不存在；部分事件没有退订。草稿改由 chat 服务按类型与 ID 持有，退出登录/卸载服务时释放 URL；组件监听配对清理。 |
| 失败后输入被清空、新输入被覆盖 | 旧逻辑不区分发送成功与失败。仅成功后清空对应原稿，等待期间新增文字保留。 |
| 上传期间切换会话发错目标 | 队列在 await 后使用当前会话。组件失效或目标变化时停止后续发送；保留原会话附件与已上传结果。 |
| 图片配文失败后重复发图 | 自动重试覆盖了上传、媒体发送与配文全部阶段。仅网络上传允许自动重试；已确认发送的媒体单独记录，配文失败只重试配文。发送超时不自动重发消息。 |
| 引用偶发消失 | 媒体发送未传 quoteId；引用目标离开消息窗口时丢失备用摘要；WS 更新未显式保留引用 ID。文本与媒体均携带引用信息，并保护切换期间的引用状态。 |
| 引用图片等显示文件名 | 通用 toText 会返回媒体 URL。摘要改为 [图片]、[视频]、[语音] 等类型；图片/表情引用增加缩略图；远端引用按会话合并请求。 |
| 网址点击不跳转 | 资源处理误改写相对 href，www 未链接化，Tauri 没有系统浏览器打开路径。保留网页链接/页内锚点，识别 www 与结尾标点；Tauri 新增只接受 HTTP/HTTPS 的原生命令。 |
| 亮色异常、文字对比度不足 | ui 切模式只改 data-theme，而 theme 插件持续保留旧模式内联变量。统一以 ui.effectiveTheme 为准，切换时重算全部表面色、文字、链接与按钮前景色；移除桌面聊天条带的大面积透明模糊。 |
| 添加好友确认框被个人资料覆盖 | 资料层级 115，确认框仅 98，且在控制台内。确认框 Teleport 到 body，层级 150。 |
| 窄屏及弹出菜单操作 | 选会话自动收侧栏；更多菜单限制在视口内并支持外部点击/Escape 关闭；附件列表限制高度；补上文件保存图标实际 import。 |
| 动画 | 通知、面板使用短距离淡入，遵循 prefers-reduced-motion；未对消息流增加持续动画。 |

## 新消息 Toast

- 免打扰会话、自发消息、当前正在查看的会话不弹通知；在其他功能页查看时仍会提醒。
- 点击通知切换到对应会话，并通过消息 ID 定位、高亮；不在最新列表内时补拉上下文。
- 实时连接和未读变化的轮询均可触发。首次加载仅建立基线，不把历史未读当新消息；轮询补拉串行执行。
- 同一会话合并为最新通知；最多 5 条；默认 6.5 秒消失；有独立关闭按钮。
- WS 重放消息去重，避免重复 Toast 与未读累计。开启免打扰时移除已显示的该会话通知。
- 退出登录清空通知和定时器；通知回调及消息定位请求不能覆盖之后手动选择的会话。

## 已运行验证

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run test:chat
npm run typecheck
npm run build
node scripts/build-server-bundle.mjs /tmp/yunhu-server-validation.mjs
git diff --check
```

`test:chat` 的 29 项离线回归测试通过。它使用真实 chat/ui/theme 实现及 Vue 编译后的 Composer setup，模拟延迟、失败、切换和组件生命周期；不连接真实账号。
对预设配色的两个模式分别检查正文对比度至少 7:1、辅助文字/链接和主按钮文字至少 4.5:1。
源码 preflight、类型检查、Vite 构建和 sidecar JavaScript 打包通过。Vite 保留单个 JS chunk 大于 500 kB 的提示，未在本轮拆包。
