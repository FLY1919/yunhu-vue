# 1.0.34

本次修改直接基于 `yunhu-richkobe-1.0.32-complete-source.zip` 的当前版本，未合入 1.0.33 的全站动画改动。

基线 ZIP SHA-256：`a2834a2b6349478c605961c19f1a6a99f2f07943bab9aea0f595bbb32e5866d2`。

## 文件消息与会话列表

- 文件卡片改用主题中性背景。文件名、文件大小、图标、下载按钮各有明确层次，长文件名自动换行，下载路径和进度功能保留。
- 打开会话记录本地排序活动，不改消息时间。置顶会话始终在前，刚打开的普通会话随后；其他会话有新消息时可排到它前面。重复推送、编辑、普通刷新不会重复上移。
- “置顶会话在前”可折叠整组置顶会话，普通会话随之上移，入口保留数量及未读提示。折叠状态按账号保存，搜索会话时仍显示折叠中的命中结果。置顶独立页签模式继续保留。

## 群聊面板

- 成员：昵称/ID 搜索、已加载成员的角色筛选、分页与失败重试、身份和禁言状态、资料、消息、提及、复制 ID、禁言、管理员、群标签及移除成员。窄屏收纳快捷操作，管理弹窗按权限展示。
- 机器人：查看群内机器人，打开资料及对话，发送机器人入群邀请，确认后移除机器人。
- 群资料：群头像、名称、简介、群主、成员入口及群状态概览；管理员可内联编辑名称和简介，保存失败保留输入。
- 群设置：个人偏好、消息通知、群管理、更多四类。保留群昵称、备注、置顶、免打扰、接收模式、邀请及分享、成员宫格、群看板、本地缓存清理和退出群聊。
- 群管理：入群免审核、新成员查看历史、私有群、隐藏群成员、消息类型限制、群文件上传限制、消息自动清理及群口令。文章、HTML、语音通话加入类型限制选项。
- 原群资料页的自动清理、群口令设置收纳到群设置的“群管理”。自动清理按接口约定提供永久保留、2 个月、1 年、2 年选项。未识别的现有值会保留显示，避免打开界面即覆盖配置。

## 动画及操作

新面板打开/关闭使用 180–220ms 的位移、缩放和透明度过渡，分类切换为 120ms，置顶折叠为 200ms。系统“减少动态效果”开启时移除位移并缩短透明度过渡。离场内容停止拦截操作，支持 Escape 关闭及弹窗焦点管理。

群资料修改按上游协议读取当前完整设置，再编码完整 protobuf 提交，保留没有编辑的配置。成员搜索使用请求序号排除旧结果，分页失败后重试原页；切换群聊后丢弃过期的成员及机器人响应。

## 验证及交付

验证使用离线虚拟账号和本地测试数据，不调用用户账号执行真实群操作。检查包括类型检查、源码 preflight、聊天回归测试、面板界面与主题对比度测试、原有界面功能回归、生产前端构建和 sidecar 端口释放测试。

Windows x64 桌面程序使用 Rust 的 `x86_64-pc-windows-gnu` 目标编译，安装包在本机通过 NSIS 生成，前端与 Node sidecar 使用本次源码重新构建。尚未在 Windows 真机登录账号进行联机群操作验收。
