# 云湖牢大版 v1.0.2

云湖第三方桌面客户端。本版修复多个接口与界面问题，并新增机器人部署能力。

## 新增

- **机器人部署**：支持创建机器人并邀请进群（机器人邀请走独立协议形态）；已验证可一键部署到自有群
- **群设置面板 QQ 化**：右侧固定面板（不遮挡聊天区）——群卡片、成员宫格（右键成员=发消息/@TA/查看资料/添加好友/禁言）、群公告、我的本群昵称、群聊备注、置顶与免打扰开关；无后端的按钮（戳一戳/举报/退出群聊等）一律不做
- **群网盘上传**：群文件面板新增「上传文件」，支持多选，直接传到当前目录
- **会话右键**：新增复制群号、标记未读（本地持久角标）
- **表情管理**：外来表情包内的表情可右键一键加入个人收藏；上传表情时过长文件名自动截短

## 修复

- **文章打不开**：实时推送的空内容会覆盖已加载的文章正文；现已做覆盖保护，文章卡片与带图文章均正常打开
- **音视频无法播放**：视频/音频按类型走正确的资源域名（此前一律按图片域名解析导致 404）
- **挂载盘文件打不开**：文件链接补认证凭据，新标签页可直接打开/下载
- **群文件目录**：修复多层目录返回上级跳级、面包屑显示错误
- **安装包体积**：安装后体积由 154MB 降至约 123MB，安装包由 113MB 降至约 92MB

## 说明

- 桌面端安装包受内核体积限制约 92MB（Electron 架构下限），安装后约 123MB
- 安卓端体验有限，推荐原生实现：[Yhchat_md3](https://github.com/Kauid323/Yhchat_md3)、[Murexide](https://github.com/murexide-project/Murexide)
