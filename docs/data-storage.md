# 数据目录与本地持久化

云湖牢大版把「登录信息与会话缓存」从浏览器 localStorage 迁到了**用户文档目录**，
换浏览器/重装系统后登录态与界面现场不再丢失。

## 目录位置

| 端 | 路径 | 说明 |
|---|---|---|
| Web / server.ts | `~/Documents/yhchat/`（Windows：`文档\yhchat`） | 默认；可用环境变量 `YH_DATA_DIR` 覆盖 |
| 桌面端（Electron） | userData 下 `yhchat/` | 经 preload + IPC 写入，随应用卸载策略 |
| 安卓端（Capacitor） | 应用私有目录 | 安卓分区存储限制，WebView 不能直写用户文档目录 |

## 文件清单（白名单，服务端只认这五个）

| 文件 | 内容 | 凭据？ |
|---|---|---|
| `session.json` | 登录 token、设备号 | **是**（退出账号即清除） |
| `cache.json` | 当前会话 id、会话列表快照（重启秒开） | 否 |
| `pin.json` | 锁屏 PIN 的 SHA-256 哈希 | 是（退出清除） |
| `lock.json` | 锁屏状态（锁着重启仍锁着） | 否 |
| `relay.json` | 手机端解锁请求/应答中继（5 分钟过期） | 否（退出清除） |

服务端端点：`GET / PUT / DELETE /data/<name>`（name 限上表五个），
单文件上限 2MB，只收合法 JSON，路径白名单防穿越。
开发环境（`npm run dev`）由 vite 中间件提供同一行为。

## 迁移与回退

- 旧版本存在 localStorage 的 `yh.token` / `yh.device` 在首次读写时**一次性迁移**进
  `session.json` 并删除旧 key，不会双份凭据。
- `/data` 端点不可用时（例如纯静态部署）自动回退 localStorage，登录不被阻塞。

## 退出账号

清除**全部本地凭据**：`session.json`、`pin.json`、`lock.json`、`relay.json`、
`cache.json` 以及 localStorage 里的旧 key。
**保留**非凭据偏好：主题/壁纸、会话分组、快捷回复、插件市场已装插件。

## 锁屏与手机端解锁

- ☰ 菜单「锁定」→ 全屏锁屏（亚克力模糊）。解锁方式二选一：
  1. 本地 PIN（4-6 位数字，首次锁定前设置，哈希存 `pin.json`）；
  2. 「手机解锁」：向云端 KV 中继写解锁请求，**同账号的手机端 App 在前台时**
     秒级弹确认窗（解锁/拒绝），桌面端轮询取回自动解锁。
- 手机端在后台时收不到推送（云湖公开接口无 push 通道），锁屏页会提示打开手机端；
  这是平台限制，不做后台推送。
- 扫码登录未做：云湖无匿名中继端点（登录前桌面端无法写账号 KV），方案不成立。
